# cfDNA End-Motif Analysis (4-mer)

This repository contains scripts to compute **cfDNA end-motif frequencies** (4-mers at 5'fragment ends) and perform downstream comparisons across different metastatic sites. 
The workflow is designed for cluster use and produces motif frequency matrices and visualization outputs.

**This workflow is based on and adapted from**:  
**Protocol for analyzing plasma cell-free DNA fragment end motifs from ultra-low-pass whole-genome sequencing**,  
by **Darren Liu et al.** (DOI: https://doi.org/10.1016/j.xpro.2024.103357)
